# Branding

*Culous Yu / C.YU MGT's personal visual identity —— colour, type, logo, and layout conventions, distilled from the brand guideline, the case-study portfolio, and culousyu.com for consistent design/visual output (HTML, slides, documents, decks). Self-contained —— all rationale is inline. C.YU MGT is not a live agency; Culous no longer runs it as a real firm, so treat this as a personal identity, not corporate brand governance —— keep design copy in a personal-portfolio register, never "our company/our team" language.*

## Colour Palette — Hard Rule

Source: `C.YU Brand Guideline.pdf` (1p, authoritative).

| Name | Hex | RGB | Role | Explicit Use(s) |
|---|---|---|---|---|
| Light Teal ("More Character") | `#20898A` | 32, 137, 138 | Accent, dark-BG text | Dot on C.YU digital logos |
| Mid Teal ("Key Brand Colour") | `#468EA1` | 70, 142, 161 | Accent, text, highlight, shape | Website/portfolio/résumé highlighted text; virtual-presentation status; portfolio stroke & shapes |
| Dark Teal ("Subtle & Wearable") | `#005166` | 0, 81, 102 | Subtle highlight, large shape, physical items | Website subtly-highlighted name; design backgrounds/shapes; phone case |
| Arancio Xanto ("Flaming Lamborghini") | `#E64A37` | 230, 74, 55 | Orange & teal, glow, CTA | Used as red in designs; P2 logos |

- Each swatch ships with a 60/70/80/90% tonal scale (tint/shade rings shown in the source guideline) —— usable for gradients, depth, or a lighter/darker variant without leaving the palette.
- Mid Teal is the default "key" colour when only one accent is wanted; Light Teal is reserved specifically for the logo dot per its explicit usage —— don't repurpose it on a whim.
- Chrome/shell only (cards, borders, section labels, backgrounds, highlighted text) stays within this 4-colour system. Content imagery (case-study stills, video frames, category thumbnails) is NOT colour-restricted —— full-saturation photography/footage sits inside neutral teal-framed containers; the restraint applies to the frame, not what it holds.

## Typography — Hard Rule

Source: same guideline page, § Typography.

| Role | Font | Notes |
|---|---|---|
| Body / Default | Avenir Book | long-form reading text |
| Heading — personal contexts | Mplus 1p Thin | pairs with `#000000` / `#FFFFFF` / `#24273A` / `#B57450` text colours |
| Heading — work/project contexts | Garamond Pro Display | serif; deliberately distinct register from personal headings —— don't cross the two |
| CTA / special highlight | MF XingHei | ⚠ non-commercial licence per the source guideline —— substitute a licensed display face before any commercial/client-facing use |

- The personal-vs-work heading split is deliberate: use Mplus 1p Thin when a heading is about Culous himself (bio, about, contact), Garamond Pro Display when it's about a project/case study/work output.
- If none of these are available in the target medium (e.g. HTML without web-font embedding), fall back to a clean geometric/humanist sans for body + personal headings and a classic serif for work headings —— keep the personal/work distinction intact even on fallback.

## Logo — Hard Rule

- Wordmark is an interlocking "CYU" monogram in thin outline stroke —— a "C" wrapping into a "Y" whose downstroke continues into a "U", with "ulous" in small script wrapping under/around the C, so the full mark reads "Culous" + "YU" together.
- The Light Teal dot is the mark's one explicit colour accent (on digital versions only).
- Appears two ways: a small solid-line badge icon (page corners/headers) or a large translucent "ghost" watermark over photography (cover/closing slides) —— never as a solid-fill logo.

## Signature Motif — Soft Pattern

- Full-bleed grey-blue ocean/wave photography is the recurring background across both formal (portfolio) and personal (website) output —— reuse it, or a close equivalent, as the default backdrop for anything representing Culous personally, rather than defaulting to a plain colour field.
- Content sits in white/off-white translucent rounded "squircle" cards (very rounded corners, thin teal-toned border) floating over the ocean —— text never sits directly on the photography.

## Layout Conventions — Soft Pattern

Observed consistently across the 22p case-study portfolio and culousyu.com; not codified in the 1p guideline itself, so treat as strong precedent rather than hard rule.

- Client/project entries: circular client-logo badge (top-left) + intro paragraph(s) in a rounded card + a structured left-side summary block (`Scale` / `Industry` / `Commissions` for commercial work, `Organisation` / `Subject` / `Grade` for academic work) + right-side stat callouts or screenshots/video.
- Stat callouts favour a big number with a `+` or `×` suffix inside a circular or triangular badge (e.g. "55,000+", "12×") —— visually distinct from prose, where root `CLAUDE.md` §2.3's superscript `⁺` rule governs instead.
- Category/section labels run as vertical rotated-text tabs in Dark Teal along a card's edge.
- Video is Vimeo-first, presented via a circular play-button badge or embedded player; show-reel-style videos open on a title card bearing the "IFYU" personal moniker (his separate handle for video/reel content, e.g. `vimeo.com/IFYU`, `instagram.com/IFYU_official`).
- Generous whitespace between sections —— pacing is unhurried and spacious, not dense.

## Voice-Adjacent Visual Patterns — Soft Pattern

For linguistic register/tone (email, DM, formality level), see `writing_style.md` —— this section is design-layer emphasis only, not a duplicate of that file.

- Inline keyword-highlighting in Mid Teal within body paragraphs draws the eye to key achievements or links.
- Quantified-achievement emphasis (%, ×-multiples, counts, `+`) is a recurring feature of case-study copy —— numbers carry the credibility.
- Bio-line formula: "[Name] is a [role], [role], [role]... with [N]⁺ years [domain] experience" —— multi-hyphenate self-positioning stated plainly up front.
