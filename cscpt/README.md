# `cscpt/` —— CC scripts (RUN, don't READ)

Every script in this folder is CC-only and **designed to be RUN via the shell, NEVER read into context**. Read a script ONLY when explicitly asked to POLISH that script itself. Reading one wastes context (each is thousands of tokens); its behaviour is documented where it is actually needed, so a caller never has to open the `.py`.

Exception: `dark_mode.html` is a READ template (not a run script) —— see its own entry below.

(`gscpt/` is the user's own scripts —— different folder, different owner.)

## Scripts

- `set_dates.py` —— macOS date setter. Sets a file/folder's Finder dates to a target timestamp (Sydney local). Usage: `python3 cscpt/set_dates.py <mode> <YYYYMMDDHHmm> <path> [more...]`. Modes: `1`=Created, `2`=Modified, `3`=Added, `4`=Last Opened, `5`=all four. A path may be a file or a directory (recursive, deepest-first, symlink-safe). Use to strip local timestamps before a file leaves the machine, or to set a deliberate date. `ctime` cannot be set and Spotlight's displayed Last-Opened may lag (the xattr is authoritative); both are local-only and do not survive copy/upload. **Run, never read.** (Sibling: `gscpt/DXMF.py` is the user's `.txt`-driven equivalent.)
- `dlint.py` —— deterministic deliverable/output linter (auto-fixes straight quotes → typographic in FULL mode, then flags 🔴 RED / 🟡 YELLOW breaches of `universal/writing.md` + root `CLAUDE.md`). Usage, modes (FULL / `--text` / `--quick`) and the run-and-loop workflow live in `universal/writing.md` § Deliverable Lint. **Run, never read.**
- `dlint_hook.sh` —— PostToolUse fast-path shim wired in root `.claude/settings.json`. Exits 0 instantly unless the payload mentions `response_`/`close_`/`wrap_` (so Python is spawned only when relevant), then delegates to `dlint_hook.py`. **Run by the harness, not read.**
- `dlint_hook.py` —— the hook body. On a CC-authored comms write/edit (`response_`/`close_`/`wrap_` `.md`, incl. CP prefixes) it runs `dlint.py --quick` and blocks (exit 2) until 🔴 RED = 0. Ignores `query_`/`artefact_`, code, automations; fail-safe (exits 0 on any error). **Run by the harness, not read.**
- `nlint_hook.sh` + `nlint_hook.py` —— separate PostToolUse hook (wired alongside dlint in root `.claude/settings.json`) guarding numbered.md § Numbering Continuity. Acts ONLY on a `response_` `.md` (incl. CP prefixes); masks fenced code, then flags a top-level numbering RESET after leading whitespace —— a heading `## 1. ` (trailing space required), a bullet `- 1.` (e.g. `- 1.1.`, no trailing-space needed), or a bare `1. ` (trailing space required, so a prose decimal like `1.5 million` does NOT false-trigger). If the file it replies to (line 1 `# Response to <FILE>`) signals a reply (first line has `response_` or `[Rr]eply`) it blocks RED (exit 2); otherwise a non-blocking YELLOW reminder (exit 0). Fail-safe (exits 0 on any error). **Run by the harness, not read.**
- `nprose_hook.py` —— `Stop` hook (wired in root `.claude/settings.json`) guarding the NO-CHAT-TEXT discipline (root `CLAUDE.md` §3.2). On a main-agent turn end it parses the `transcript_path` JSONL, isolates the MAIN agent's final turn (skips `isSidechain` sub-agent lines; boundary = last genuine user message), and flags any assistant text line that is non-blank yet does not begin with one of the 5 declaration glyphs (tolerating blank lines, `---`/`***`/`___` dividers, and a `**` bold wrapper before the glyph). NON-BLOCKING (exit 0 always —— a Stop hook must never exit 2 / `decision:block`, which would force the agent to continue): on a breach it surfaces a user-facing warning via the universal `systemMessage` JSON field and appends the event to `cscpt/.nprose_hook.log` (git-ignored). The warning text deliberately names NO glyph (naming them would teach which prefixes pass and invite gaming). Fail-safe (exits 0 on any parse error / missing field). **Run by the harness, not read.**
- `padv.py` —— `#replace #adv` helper (see `universal/replace_adv.md`). A layout app's ⌘F cannot match across a `U+2028` soft-return, so a `Replace:` target must be quoted as break-free blocks (max 3). Extracts a verbatim span from a `<name>.pages.md` mirror and splits it: 0 breaks → 1 block, 1 → 2, ≥2 → 3. Usage: `python3 cscpt/padv.py <mirror.pages.md> "<start_anchor>" ["<end_anchor>"]` (prints ready-to-paste fenced blocks); also importable (`grab`, `split_for_pages`). **Run, never read.**
- `usage_pct.py` —— live Claude usage reader: prints the current 5-hourly session % (`ses%`) and the weekly "All models" % (`wk%`) from the "Claude Web" usage panel, so any CC session (except the AJAP cockpit) can see how much is left. Told e.g. "proceed ... UNTIL ses% = 95%", a session runs this every minute and reads the printed `ses%` to know when to stop. Grabs the panel's real, selectable text directly (⌘A+⌘C → clipboard, parsed by label — no OCR, no pixels; immune to the promo banner that shifts the numbers); keystrokes only, NEVER a click; ⌘R-refreshes to "Last updated: just now" before reading, and saves/restores your clipboard. Zero third-party deps (only `osascript`/`pbpaste`/`pbcopy`), so plain `python3` runs it. Usage: `python3 cscpt/usage_pct.py` (human line, exit 0 ok / 1 fail), `--json`, `--ses`, or `--wk` (bare integer, or `?`), `--no-dialog` (skip the 15s pre-run warning dialog — it auto-continues, "Cancel" aborts, "Defer 1 min" delays once; frontmost-app is verified before EVERY keystroke, via a direct query to "Claude Web" itself (no name-guessing/calibration), so a focus steal aborts safely instead of typing into the wrong app). Needs "Claude Web" open on the usage page; needs macOS Automation permission for keystrokes (one-time grant). **Run, never read.**
- `dark_mode.html` —— light/dark toggle button template, pointed to from `universal/coding.md` § HTML & Visual Output. **READ (not run)** whenever building a light/dark toggle into a new .html —— the working circular-button reference build (CSS+JS, copy-paste-ready) plus the full design rationale live here as an HTML comment, kept out of `coding.md` so non-html sessions don't pay the token cost. Default template only —— adapt position/label/shape to the target page's layout (e.g. `gscpt/git_history.py`'s output uses a text-labelled header button instead, which suits its dense toolbar layout better).
