# Changes —— `changes_202607042016`
*Root-cause fix for the CL-violation false positives (`query_202607042008`). Both the live gate (`cl_check.py`) and the analytics (`ajap_logs.py`) scanned from the `## 6.` marker to END OF FILE, so a clean CL followed by a legitimate `## 7. Employer Questions` section false-flagged the P.S. check (P.S. is the LAST line of the CL, not of the file) and any dash in a Q&A answer. Fix: bound the scan to the CL SECTION only (`## 6.` marker → next `## ` heading / EOF). Standard `replace.md` direction. Tested: the 3 flagged recent ARs → only the 1 REAL one (Pendulum) stays flagged; the 2 clean ones (Henderson, Leisures) now pass.*

## Change 01 —— `seek/context/cl_check.py` bound the CL to its section
**Replace:**
```
    cl = content[m.start():]

    # HARD: dash/plus symbols
```
**With:**
```
    # Bound the CL to its OWN section: from the `## 6.` marker to the NEXT
    # `## ` heading (e.g. `## 7. Employer Questions`) or EOF. Checks must NOT
    # bleed into later AR sections —— the CL's P.S. is the last line of THIS
    # section, not the file, and a Q&A answer's dash is not a CL violation.
    rest = content[m.end():]
    nxt = re.search(r"^##\s", rest, re.MULTILINE)
    cl = content[m.start(): m.end() + nxt.start()] if nxt else content[m.start():]

    # HARD: dash/plus symbols
```

## Change 02 —— `seek/context/cl_check.py` P.S. = last content line of the CL section
**Replace:**
```
    # HARD: P.S. tail must be the exact final line
    stripped = content.rstrip()
    last_line = stripped.splitlines()[-1] if stripped else ""
    if last_line != PS_REQUIRED_TAIL:
        hard.append("file does NOT end with the exact required P.S. line")
```
**With:**
```
    # HARD: P.S. must be the LAST content line of the CL SECTION (not the file
    # —— later AR sections like `## 7. Employer Questions` legitimately follow).
    # Drop trailing blank lines and a trailing `---` separator, then compare.
    cl_lines = cl.splitlines()
    while cl_lines and (not cl_lines[-1].strip() or set(cl_lines[-1].strip()) <= {"-"}):
        cl_lines.pop()
    last_line = cl_lines[-1].strip() if cl_lines else ""
    if last_line != PS_REQUIRED_TAIL:
        hard.append("CL does NOT end with the exact required P.S. line")
```

## Change 03 —— `gscpt/ajap_logs.py` same CL-section bounding in `scan_applied_violations`
**Replace:**
```
        # --- Type 1: rule-violation symbols after the Cover Letter marker ---
        marker_match = re.search(
            r"##\s+\d+\.\s+Cover Letter",
            content,
        )

        if marker_match:
            scan_content = content[marker_match.start():]
            total += sum(
                scan_content.count(symbol)
                for symbol in RULE_VIOLATION_SYMBOLS
            )

        # --- Type 2: file must END with exactly PS_REQUIRED_TAIL ---
        # rstrip() tolerates an invisible trailing newline / spaces after the
        # period, but any real text after the line fails the check.
        stripped = content.rstrip()
        last_line = stripped.splitlines()[-1] if stripped else ""
        if last_line != PS_REQUIRED_TAIL:
            total += 1
```
**With:**
```
        # --- Bound the CL to its OWN section: `## N. Cover Letter` marker to the
        # NEXT `## ` heading (e.g. `## 7. Employer Questions`) or EOF. Later AR
        # sections are NOT part of the CL and must not be scanned (their dashes
        # are not CL violations, and the P.S. is the last line of THIS section,
        # not of the file). ---
        marker_match = re.search(
            r"##\s+\d+\.\s+Cover Letter",
            content,
        )

        if marker_match:
            rest = content[marker_match.end():]
            nxt = re.search(r"^##\s", rest, re.MULTILINE)
            cl = (
                content[marker_match.start(): marker_match.end() + nxt.start()]
                if nxt else content[marker_match.start():]
            )

            # Type 1: rule-violation symbols within the CL section.
            total += sum(cl.count(symbol) for symbol in RULE_VIOLATION_SYMBOLS)

            # Type 2: P.S. must be the LAST content line of the CL section
            # (drop trailing blank lines and a trailing `---` separator).
            cl_lines = cl.splitlines()
            while cl_lines and (
                not cl_lines[-1].strip() or set(cl_lines[-1].strip()) <= {"-"}
            ):
                cl_lines.pop()
            if (cl_lines[-1].strip() if cl_lines else "") != PS_REQUIRED_TAIL:
                total += 1
```
