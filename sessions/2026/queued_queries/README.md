# Queued Queries

## Basics
- This folder stores queries written by user during sesL
- Unless asked to, CC should never visit this folder

## Organisation
If a file in this folder was directly sent in chat, do sequentially:
- Rename as `*_query_[current_TS].md` (prefix CP if in CP)
- Move to `sessions/[YYYY]/[YYYYMM]/`
- Briefly note in chat
- Address it as usual

## FYI
- If this folder isn't empty (except this file), the user probably forgot to send them
- Filenames are temporarily shown as CC session names they would be sent to
- Right before sending, user is supposed to rename & move as told above
