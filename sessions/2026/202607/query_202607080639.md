# Batch Moving Python Script

based on `nscpt/git_move_rename.sh`, create `nscpt/git_move_batch.py` (ensure to make ample top comment in case i forgot how to use it; ref `gscpt/quote_fix.py` on how the top comment should be written) that create the .sh which moves a large amount of files from one location to another, assuming no rename needed
when run, if no `nscpt/gmb_*.md` found, follow 1st stage; if found, follow 2nd stage (see below)
---
1st stage:
input = none
output = `gmb_[current_TS].md` = below template (for user to fill in)

```
# Batch Moving [current_TS]

## From


## To

```
---
1st stage explainer:
[current_TS] = `TZ='Australia/Sydney' date +"%Y%m%d%H%M"`
anything below `## From` AND above `## To` = folders/files to move; 1 line = 1 folder/file
if folder, move all files & subfolders (inc. their contents) inside this folder
if file, move this file
below `## To`:
- if nothing, output error in stage 2 (same for below)
- if more than 1 line, output error
- if 1 line but not a single folder path, output error
- if 1 line and a single path but not folder (i.e. file), output error
- if 1 line and a single folder path, identify it as moving destination for all files
---
example of filled 1st stage template:
```
# Batch Moving [current_TS]

## From
'/Volumes/FURY 2TB/Fury Documents/GitHub/dupbus-ceztuc-7cufVe/temp/temp_misc'

## To
'/Volumes/FURY 2TB/Fury Documents/GitHub/dupbus-ceztuc-7cufVe/nscpt'
```
---
meaning:
move everything inside `temp_misc/` to `nscpt/`
since `temp_misc/` has a subfolder (`cd_teset/`) which contains a file (`test-100.html`), that means moving that single file to `nscpt/`
and by moving, it means stage 2 to create the required .sh for user to review then run (see below)
---
stage 2:
input = `nscpt/gmb_*.md`
output = `nscpt/gmb_[match_TS].sh` + terminal output (see below)
---
stage 2 ops:
if any conditions above ("..., output error") detected, output error
if multiple `nscpt/gmb_*.md` detected, output error
only run if correct input was detected successfully, creating the .sh as said ([match_TS] = the TS of input `gmb_*.md`), then terminal output:
- notify success; print filename (`gmb_[match_TS].sh`)
- ask to review then confirm by typing `yes`
---
stage 2 final actions:
when terminal input `yes` received, directly run the just created `gmb_[match_TS].sh`
then check if the git mv succeeded
if yes, terminal output notify success, then void the input `gmb_*.md` AND the just created `gmb_[match_TS].sh` (user to manually delete)
if no, terminal output the error (e.g. "Uncommitted changes detected. Commit or stash them first.")
