## Typography
remark/clarification:
Mplus 1p Thin (usually used in larger font size but very thin weight; e.g. body is 12pt Avenir Book, Heading is 20~30pt Mplus 1p Thin) is only for highly personal context (as you noted), like my website sections' headings; never use it in formal deliverable (unless it's for highly creative industry which i no longer actively participate in) because generally speaking it's considered "unprofessional" and rather playful/unconventional/hard to read
in opposite, Avenir is extremely versatile (almost like Arial) and widely accepted & well-received (zero backlash on its use over decade, even when im STRICTLY mandated to use Arial only, which i still used Avenir anyway)
the 4 colours in "Notes" col of "Mplus 1p Thin" is NOT exclusive to this font but for all 4 fonts, where the default is #24273A (deliberately tuned to look like black but not black, which is my signature and "less boring"), which i use it for 99.9% content
#FFFFFF is ~99.9% for white text on dark bg (e.g. my dark teal)
#000000 is extremely rare, almost exclusive to legal doc
#B57450 is mostly for highlight text (when i decided for some reason NOT to use white text on dark bg), somewhat rare but still used sometimes; it's also used to distinguish from body text, like it's my default .pages templates (casual use only) header/footer so it's clear what are body text
re "Avenir":
the heaviest weight of Avenir is not "Heavy" but "Black" (not a colour), however usually bolding (⌘B) w/ "Heavy" suffices, "Black" is reserved for extreme highlight (typically only 1 use in each piece)
in sum, default = "Book"; remarks = either "Light" or smaller font-size "Book"; subtle highlight (usually for longer highlight) = "Medium"; normal highlight (usually for shorter highlight) = "Heavy"; extreme highlight = "Black"
.
re "Garamond Pro Display":
as you noted, it's the counterpart of "Mplus 1p Thin" but for formal/professional use cases where Serif is expected, NEVER ever use it for body text as i found it very difficult to read when it's long
IMPORTANT: "Garamond" is very tightly kerned which is bad, so whenever i use it i ALWAYS apply double space between words; e.g. `This  is  a  Title`
.
for both "Mplus 1p Thin" & "Garamond Pro Display":
100% MUST be Title Case
.
re "MF XingHei":
`(Non-commercial)` is part of the font name and doesnt actually mean ANYTHING at all
it is quite rare to use; but when it's used, it can be either ALL CAPS or Title Case
it is the single rarest element used across my whole brand guideline, even rarer than the use of Arancio Xanto because it is very "unprofessional" and hard to read, yet it is very effective to stand out like nobody can miss it at all
this font is quite small by default so whenever using it, the font size typically jump 50%~100% to even just reach the normal size; and since it's for highlight, it's usually made even larger
so at the end of the day it might easily be 100%~150% larger than body text
.
re "The personal-vs-work heading...":
no, that concerns personal and work use case, not the content
e.g. on my website (personal use), i use Mplus 1p Thin even content is about my works
e.g. on my formal/professional docs, i use Garamond Pro Display even content is about my private life
.
re "If none of these are available...":
actively install required packages to enable them
if truly have to fall back (alert user; this is highly provoking), use Helvetica Neue throughout (no Serif is accepted except Garamond; explicit blacklist: Times New Roman, considered unacceptably ugly); if still not available, last resort is Arial
